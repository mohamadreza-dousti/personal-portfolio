# personal portfolio
A personal portfolio website built with **Django** **HTML** **CSS** to showcase my skills, projects, experience, and education.

## Main Features

- Single-page portfolio
- Navigation between sections
- Dynamic project management
- Dynamic skills management
- Dynamic language management
- Dynamic education management
- Dynamic experience management
- Contact form
- Admin paneL

## Website Sections

1. Navbar
2. Hero
3. Skills & Languages
4. Projects
5. Education
6. Experience
7. Contact
8. Footer

## Content Requirements

### Static Section

The following sections are static and will not be managed through the admin panel:

- Navbar
- Hero
- Contact
- Footer

### Dynamic Section

The following content will be managed through the admin panel:

- Skills
- Languages
- Projects
- Education
- Experience
